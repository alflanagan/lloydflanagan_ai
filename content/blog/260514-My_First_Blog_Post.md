So! Welcome to my blog, where I'll be posting various discussions of matters technical, hopefully without too many tangents.

I create a blog post by creating a file in the `content/blog` directory, with
the title and publication date specified by convention in the filename. The
contents of the file will be converted to HTML by the
[marked](https://marked.js.org) JavaScript package, using the [GitHub Flavored
Markdown](https://marked.js.org/#specifications) flavor (but adhering to the
[CommonMark specification](https://commonmark.org) as much as possible.
